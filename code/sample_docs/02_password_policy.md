# パスワードポリシー（社内規定）

## 1. 目的
本規定は、TechFlow株式会社（以下「当社」）の情報システムにおけるパスワードの設定・管理に関する基準を定め、不正アクセスによる情報漏えいを防止することを目的とする。

## 2. パスワードの複雑性要件
社内システムで使用するパスワードは、以下の条件をすべて満たさなければならない。

- 12文字以上であること
- 英大文字・英小文字・数字・記号のうち3種類以上を含むこと
- 社員ID、氏名、生年月日など推測されやすい情報を含まないこと
- 過去に使用した直近5世代のパスワードと同一でないこと

## 3. パスワードの変更頻度
全社共通システム（社員ポータル、メール、VPN）のパスワードは**90日ごと**に変更が必須である。変更期限の7日前から、ログイン時に変更を促す通知が表示される。

## 4. アカウントロックについて
ログイン試行に**5回連続で失敗**した場合、アカウントは自動的にロックされる。ロック解除は以下のいずれかの方法による。

1. 30分経過後の自動解除を待つ
2. ITヘルプデスク（内線1234）へ本人確認のうえ依頼する

## 5. 多要素認証（MFA）
社外からVPN経由で社内システムにアクセスする場合、パスワードに加えてスマートフォンアプリによるワンタイムパスコード（OTP）の入力が必須である。MFAアプリの初期設定はPC貸与時にITヘルプデスクが実施する。

## 6. 禁止事項
- パスワードを付箋等に書き留めてPCやモニターに貼付する行為
- 同一パスワードを複数の社内外システムで使い回す行為
- パスワードを他者（同僚・上司を含む）に口頭・メール等で共有する行為

## 7. 違反時の対応
本ポリシーに違反した場合、情報セキュリティ委員会の判断により、アカウントの一時停止や懲戒処分の対象となることがある。
