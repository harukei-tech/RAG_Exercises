# 情報セキュリティ基本規定（抜粋）

## 第1条（目的）
本規定は、TechFlow株式会社の保有する情報資産を、紛失・漏えい・改ざん・不正利用等の脅威から保護し、事業の継続性を確保することを目的とする。

## 第2条（適用範囲）
本規定は、正社員・契約社員・派遣社員・業務委託先を含む、当社の情報資産にアクセスするすべての者に適用する。

## 第3条（情報資産の分類）
情報資産は重要度に応じて以下の4段階に分類する。

| 分類 | 説明 | 例 |
|---|---|---|
| 極秘 | 漏えいすると事業に重大な損害を与える情報 | 未公開の財務情報、M&A関連資料 |
| 秘密 | 社内外に限定的に開示される情報 | 顧客個人情報、人事評価情報 |
| 社外秘 | 社内での利用に限定する情報 | 内部会議資料、社内マニュアル |
| 公開 | 一般に公開してよい情報 | プレスリリース、採用情報 |

「秘密」以上に分類される情報を社外に持ち出す場合、部門長の事前承認が必要である。

## 第4条（デバイスの管理）
1. 会社貸与のPC・スマートフォンは業務目的以外での使用を禁止する。
2. 私物デバイスでの業務利用（BYOD）は、情報システム部が許可した機種・アプリに限り認める。
3. デバイスの紛失・盗難が発生した場合、発見後**1時間以内**にITヘルプデスクへ報告しなければならない。

## 第5条（ソフトウェアの利用）
会社が許可していないソフトウェア（フリーソフト、私物クラウドストレージ等）を業務PCにインストール・利用することを禁止する。生成AIツールについても、情報システム部が許可したもの以外は業務利用を禁止する。

## 第6条（メールの取り扱い）
1. 不審なメールの添付ファイルやリンクを開いてはならない。不審なメールを受信した場合は、開封せずITヘルプデスクへ転送すること。
2. 「秘密」以上の情報を含むメールを送信する際は、暗号化ZIP等の保護措置を講じること。

## 第7条（インシデント発生時の対応）
情報漏えい、不正アクセス、マルウェア感染等のセキュリティインシデントを認知した場合、発見者は直ちに以下の手順に従うこと。

1. 該当端末をネットワークから切断する（ケーブルを抜く、Wi-Fiをオフにする）
2. 端末の電源は切らずにそのままの状態を保持する
3. ITヘルプデスク緊急連絡先（内線9999）へ即時報告する

## 第8条（違反時の措置）
本規定に違反した者は、就業規則に基づき懲戒処分の対象となる場合がある。重大な違反については、法的措置を検討する。

## 附則
本規定は2025年4月1日より施行する。
