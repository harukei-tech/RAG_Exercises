# ITヘルプデスク よくある質問（FAQ）

## Q1. PCが起動しません。どうすればよいですか？
まず電源ケーブルとACアダプタの接続を確認してください。次に電源ボタンを10秒以上長押しして強制終了し、再度起動を試してください。それでも改善しない場合は、内線1234（ITヘルプデスク）まで連絡し、資産管理番号（PC本体底面のシールに記載）を伝えてください。

## Q2. Wi-Fiに接続できません。
社内Wi-Fi「TechFlow-Secure」への接続には、社員IDとパスワードによる認証が必要です。パスワードを3回連続で間違えるとアカウントが15分間ロックされます。ロックされた場合は自動的に解除されるまでお待ちいただくか、ヘルプデスクに連絡してください。ゲスト用Wi-Fi「TechFlow-Guest」は認証不要ですが、社内システムへはアクセスできません。

## Q3. メールが届きません・送信できません。
送信できない場合、添付ファイルのサイズが25MBを超えていないか確認してください。25MBを超えるファイルは共有ドライブにアップロードし、リンクを共有する運用としています。受信できない場合は、迷惑メールフォルダを確認したうえで、フィルタ設定を見直してください。

## Q4. パスワードを忘れてしまいました。
社員ポータルのログイン画面から「パスワードを忘れた方はこちら」を選択し、登録済みの社員メールアドレス宛にリセット用リンクを送信できます。リンクの有効期限は発行から30分です。ポータルにアクセスできない場合は、直属の上司またはヘルプデスクに本人確認のうえ再設定を依頼してください。

## Q5. ソフトウェアのインストール許可がほしいです。
業務用ソフトウェアのインストールには情報システム部の事前承認が必要です。社員ポータルの「ソフトウェア申請」フォームから、ソフトウェア名・利用目的・利用期間を記入して申請してください。承認までの標準対応期間は2営業日です。無許可でのインストールはセキュリティポリシー違反となります。

## Q6. プリンターで印刷できません。
まずプリンターの電源とネットワークケーブル（またはWi-Fi接続）を確認してください。次にPC側のプリンタードライバーが最新か確認し、必要であれば社内ポータルの「プリンタードライバー一覧」から再インストールしてください。用紙切れやトナー切れの表示がある場合は、各フロアの備品管理担当者に連絡してください。

## Q7. ヘルプデスクの対応時間は？
平日9:00〜18:00です。緊急度の高い障害（全社的なシステム停止など）については、24時間対応の緊急連絡先（内線9999）をご利用ください。土日・祝日は緊急連絡先のみの対応となります。
