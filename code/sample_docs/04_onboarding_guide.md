# 新入社員PCセットアップガイド

## はじめに
本ガイドは、入社初日に行うPC・各種アカウントのセットアップ手順をまとめたものです。不明点があれば、配属部署のOJT担当者またはITヘルプデスク（内線1234）に確認してください。

## 1. PC貸与時の確認事項
情報システム部からPCを受け取る際、以下を必ず確認してください。

- 本体底面の資産管理番号シールが貼付されていること
- 貸与品リスト（PC本体、ACアダプタ、マウス）と実物が一致していること
- 「貸与機器受領書」に署名し、その場で情報システム部担当者に提出すること

## 2. 初回ログイン
1. 電源を入れると初期設定ウィザードが起動する。
2. 人事部から事前に送付された「社員ID」と「初期パスワード」でログインする。
3. 初回ログイン時は必ずパスワードの変更を求められる（パスワードポリシーに準拠した新パスワードを設定すること）。
4. 続けてMFAアプリ「TechFlow Authenticator」の初期登録を行う。

## 3. メールアカウントの設定
社員メールアドレスは `姓名のローマ字@techflow.example.co.jp` の形式で自動発行されます。初回ログイン後、メールクライアントが自動的に設定されますが、反映まで最大30分かかる場合があります。

## 4. 必須研修の受講
入社1週間以内に、社員ポータルの「必須研修」から以下を受講してください。

- 情報セキュリティ基礎研修（所要時間 約60分）
- コンプライアンス研修（所要時間 約45分）
- ハラスメント防止研修（所要時間 約30分）

未受講のまま2週間が経過すると、上長宛に自動リマインドが送信されます。

## 5. Wi-Fi・VPNの設定
社内では「TechFlow-Secure」に接続してください（接続方法はFAQ Q2を参照）。在宅勤務が発生する部署に配属された場合は、配属初日にVPN接続設定ガイドに沿って設定を行ってください。

## 6. 座席・入館証について
入館証（ICカード）は総務部から貸与されます。紛失した場合は速やかに総務部（内線5678）へ連絡し、再発行を依頼してください。紛失時の再発行手数料は1,000円です。
