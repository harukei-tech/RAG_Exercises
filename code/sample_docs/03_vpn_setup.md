# 社外からのVPN接続設定ガイド

## 対象者
在宅勤務・出張時など、社外ネットワークから社内システムへアクセスする必要がある全社員。

## 事前準備
1. 貸与PCに「TechFlow VPN Client」がインストールされていることを確認する（未インストールの場合はソフトウェア申請フォームから申請）。
2. スマートフォンにMFA（多要素認証）アプリ「TechFlow Authenticator」を導入し、初期登録を完了しておく。
3. 社員ポータルで発行される「VPN接続証明書」をダウンロードしておく（有効期限1年、失効30日前に更新通知あり）。

## 接続手順
1. TechFlow VPN Clientを起動する。
2. サーバーアドレスに `vpn.techflow.example.co.jp` を入力する。
3. 社員IDとパスワードを入力する。
4. スマートフォンのMFAアプリに表示される6桁のコードを入力する。
5. 「接続」ボタンを押すと、通常5〜10秒程度で接続が完了する。

## よくあるトラブル

### 接続に失敗する（エラーコード VPN-101）
証明書の有効期限切れが原因であることが多い。社員ポータルから証明書を再発行し、VPN Clientに再インポートする。

### 接続はできるが社内システムにアクセスできない
自宅などのルーターがVPNパススルー機能に対応していない可能性がある。ルーターの設定画面で「IPsec パススルー」または「VPN パススルー」を有効化する。

### MFAコードが「無効」と表示される
スマートフォンとPCの時刻がずれているとMFAコードが無効になる場合がある。スマートフォンの「自動時刻設定」を有効にして再試行する。

## 接続の制限事項
- 同時接続は1社員につき1台のPCまで。
- 接続の最大連続時間は12時間で、それを超えると自動切断される。
- 私物PC・私物スマートフォンからのVPN接続は原則禁止（情報システム部長の特別承認がある場合を除く）。
